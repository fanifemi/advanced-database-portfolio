d. WRITE SKEW — rule: a Tier-2 customer's COMBINED debits today across all accounts must not exceed N200,000.
   Wallet sends N150,000 and savings vault sends N90,000 at the same moment (combined N240,000).
   Each session checks the combined total, sees room, then debits a DIFFERENT row — no row is written by both.

   REPEATABLE READ                      | S1 saw N0 -> debited N150,000 COMMITTED | S2 saw N0 -> debited N90,000 COMMITTED | combined debited N240,000 -> RULE VIOLATED (write skew)
   SERIALIZABLE                         | S1 saw N0 -> debited N150,000 COMMITTED | S2 ABORTED by database: 40001 could not serialize access due to read/write dependencies am | combined debited N150,000 -> rule held
   READ COMMITTED + lock customer row   | S1 saw N0 -> debited N150,000 COMMITTED | S2 saw N150,000 already debited -> REJECTED by check | combined debited N150,000 -> rule held
